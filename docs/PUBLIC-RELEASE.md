# Public release scope

This is a clean source snapshot, not a mirror of production Git history. Private PDFs, campaign photos, original IP artwork, run traces, cloud access configuration, workspace identifiers and populated credentials are excluded. Seeds, closeout examples and knowledge texts are synthetic. Five Dify DSL templates retain the node logic but use placeholder tool and dataset bindings; users must rebind them. Test assertions use mocks and do not establish business acceptance. The production Site is not made public by this release.

No new source-code license has been selected. Public visibility is not a grant of unrestricted reuse; third-party components retain their own licenses.
